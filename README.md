# surge.config

Surge 配置与策略组图标库合集。

| 文件 | 说明 |
| --- | --- |
| surge.conf | Surge 配置（Rabbit-Spec Surge-EN，我的节点已填入 SNTP 的 Surge 订阅链接） |
| Quremini.json | 图标库（Koolson/Qure，347 个，含 Emby、Nintendo） |
| icons-all.json | 图标库（fmz200/wool_scripts，1608 个，含 Emby、switch） |
| ligeicon.json | 图标库（lige47/QuanX-icon-rule，1025 个，含 Emby、Switch） |

surge.conf 可通过 raw 链接从 URL 导入 Surge；三个 JSON 可在客户端的图标库中添加对应 raw 链接使用。
